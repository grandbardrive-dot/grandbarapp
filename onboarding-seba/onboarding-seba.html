La regla que no se rompe

El portal se publica solo con git push

Netlify publica automáticamente al pushear a main. Nunca uses netlify deploy ni arrastres carpetas: el próximo push de otra persona reconstruye desde GitHub y borra lo que subas por afuera. Y siempre git pull antes de empezar (trabajan varios en el mismo repo).

git pull → editás → git commit → git push → online en ~1 min

Dos cosas que muerden

Gotchas para tener a mano

Verificar JS cuidado

Los .js son ES modules. node --check archivo.js da un OK falso. Verificá copiándolo a .mjs — si no, un paréntesis suelto deja una pantalla en blanco.

Push 403 git

La PC tiene dos cuentas de GitHub. Si el push da Permission denied, es la otra cuenta. En grandbar-hub ya está resuelto con el usuario en la URL del remote.

Tu primera misión, en detalle

Automatizar Pernod Ricard Q4

El portal ya muestra el incentivo (tabla incentivos_snapshots en la base del Hub). Hoy el avance se carga a mano; tu trabajo es que se cargue solo.

  • El dato sale del ERP Aikon (empresa 3333 CUBOS, solo lectura). No se alcanza desde la nube: el script corre en una PC/servidor de GrandBar.
  • El script consulta el ERP, calcula el avance con las reglas del incentivo y hace upsert del JSON en incentivos_snapshots.
  • Corre todos los días a las 06:00 (Programador de tareas de Windows).
  • Validá contra los números de control del documento de traspaso antes de darlo por bueno.
